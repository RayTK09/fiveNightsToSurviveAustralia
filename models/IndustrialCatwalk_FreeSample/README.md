# Industrial Catwalk — Free Sample

Бесплатный модуль из Industrial Catwalk Kit Vol.1 от Deck Zero Assets.
A free sample from Industrial Catwalk Kit Vol.1 by Deck Zero Assets.

## Внутри / Contents
- SM_IK_Catwalk_200 — настил 2 м / 2 m deck
- SM_IK_Railing_200 — перила 2 м / 2 m railing
- Варианты / variants (FBX): SM_IK_Catwalk_200_Rusty, SM_IK_Catwalk_200_Damaged, SM_IK_Catwalk_200_Hatch, SM_IK_Railing_200_Bent
  Сильная ржавчина у Rusty собирается мастер-материалом в UE-проекте полного кита (маска в вертексных цветах IK_Mask); в FBX меш идёт с базовыми текстурами.
  The heavy-rust look of Rusty comes from the full kit's UE master material (vertex-colour mask IK_Mask); in FBX the mesh uses the base textures.
- FBX: 6 мешей, LOD0–2, UCX-коллизии / 6 meshes, LOD0–2, UCX collisions
- glTF 2.0 — настил и перила / base deck and railing (текстуры в общей папке Textures / textures in the shared Textures folder)
- Textures: PBR 2K — BaseColor, Normal DX (_N) и OpenGL (_N_GL), ORM, маска решётки для LOD1–2 / grating mask for LOD1–2

## Сборка / Assembly
Сетка 100 см, реальный масштаб, пивот — верх настила.
100 cm grid, real-world scale, pivot at the top of the deck.

Unreal Engine: Import FBX, включите Combine Meshes = off, Import Collision = on (UCX подхватятся автоматически).
Unreal Engine: Import FBX with Combine Meshes off and collision import on (UCX is picked up automatically).
